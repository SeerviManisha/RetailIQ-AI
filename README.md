# RetailIQ AI

AI-Powered Retail Business Intelligence Platform

## Overview

RetailIQ AI is a full-stack retail analytics platform that provides business insights through interactive dashboards, customer analytics, inventory monitoring, sales forecasting, and Power BI reports.

## Features

* Dashboard with key business metrics
* Inventory Management
* Customer Analytics
* AI-Generated Business Insights
* Sales Forecasting
* Power BI Visual Reports
* Modern Dark-Themed UI
